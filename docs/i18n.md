# Internationalization (i18n) Implementation

## Overview

This document describes the internationalization setup for the Krogguiden Map application, supporting Swedish and English languages.

## Quick Start

The app automatically detects the browser language. If your browser is set to Swedish (`sv` or `sv-SE`), the app displays in Swedish. Otherwise, it defaults to English.

Users can manually switch languages using the language toggle button in the header (displays "EN" or "SV").

## Tech Stack

- **i18next** - Core internationalization framework
- **react-i18next** - React bindings for i18next
- **i18next-browser-languagedetector** - Automatic browser language detection

## Language Detection

Languages are detected in this priority order:

1. **localStorage** - User's previous selection (persisted as `i18nextLng`)
2. **Browser language** - `navigator.language` / `navigator.languages`
3. **Fallback** - English (default)

If the browser language starts with `sv` (e.g., `sv`, `sv-SE`), Swedish is used automatically.

## File Structure

```
src/i18n/
├── index.ts              # i18n configuration and initialization
└── locales/
    ├── en.json           # English translations
    └── sv.json           # Swedish translations
```

## Translation Key Convention

Keys use dot notation with component/feature prefixes:

```json
{
  "header.search": "Search restaurant...",
  "filters.title": "Filter",
  "filters.clear": "Clear all filters",
  "detail.hours": "Opening hours",
  "common.restaurants": "{{count}} restaurant",
  "common.restaurants_other": "{{count}} restaurants"
}
```

### Namespaces

All translations use the default `translation` namespace for simplicity.

### Pluralization

i18next handles pluralization automatically:
- `_other` suffix for plural forms
- `{{count}}` interpolation for numbers

## Usage in Components

```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('header.title')}</h1>
      <p>{t('common.restaurants', { count: 42 })}</p>
    </div>
  );
}
```

## Language Switcher

A language toggle is available in the header, allowing users to manually switch between Swedish and English. The selection is persisted to localStorage.

## Adding New Translations

1. Add the key to both `en.json` and `sv.json`
2. Use the `t()` function in components
3. For interpolation, use `{{variable}}` syntax

## Type Safety

TypeScript types are inferred from the English translation file, providing autocomplete and compile-time checking for translation keys.
